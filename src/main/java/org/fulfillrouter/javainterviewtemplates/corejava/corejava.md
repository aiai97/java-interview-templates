1. Core Java

Q1. What is the difference between JDK, JRE, and JVM?

Answer: The JVM runs Java bytecode. The JRE provides the environment to run Java applications. The JDK includes the tools needed to develop Java applications.

Q2. What is the difference between an interface and an abstract class?

Answer: An interface defines a contract, while an abstract class can provide shared state and implementation. A class can implement multiple interfaces but extend only one class.

Q3. What is the difference between == and equals()?

Answer: For objects, == compares references, while equals() compares logical equality if the class overrides it. For primitive types, == compares values.

Q4. Why is String immutable in Java?

Answer: A String cannot be changed after creation. Immutability improves security, thread safety, and the reliability of string pooling and hash codes.

Q5. What is the difference between overloading and overriding?

Answer: Overloading means using the same method name with different parameter lists. Overriding means a subclass provides its own implementation of an inherited method.

Q6. What are the four principles of OOP?

Answer: They are encapsulation, inheritance, polymorphism, and abstraction. They help organize code, manage complexity, and improve reusability.

Q7. What is the difference between checked and unchecked exceptions?

Answer: Checked exceptions must be caught or declared. Unchecked exceptions are subclasses of RuntimeException and do not have this requirement.

Q8. What is the difference between List, Set, and Map?

Answer: A List allows duplicates and preserves order. A Set stores unique elements. A Map stores key-value pairs with unique keys.
